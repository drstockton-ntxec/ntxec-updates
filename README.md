# ntxec-updates

Hosting for district-branded weekly legislative updates at https://updates.ntxec.org.

- Published pages live at the repo root, one folder per district (for example `dallas-isd/`).
- The build system and weekly content are in `source/`. See `source/README.md` for the workflow.
- To publish a new issue: build from `source/`, copy `source/dist/*` to the repo root, commit and push.
